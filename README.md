# Shuyi Wang · 王舒逸

Bilingual academic personal homepage, built with plain HTML, CSS and JavaScript. No dependencies or build step.

## Edit

Edit `index.html` to update the biography, research interests, publications, and education. English and Chinese content use the `en` and `zh` classes. The language button switches between them.

## GitHub Pages

In this repository, open Settings → Pages. Under Build and deployment, select Deploy from a branch, choose main and / (root), then click Save. GitHub displays the live URL when deployment completes.

Expected site address: https://computerwsy.github.io/

## Local preview

Open index.html in a browser, or run `python -m http.server 8000` from the repository directory.
